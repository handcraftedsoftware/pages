## Для чего это приложение

Это первая ступень перед более сложной тренировкой чтения по слогам.

Приложение подходит для короткой совместной практики, когда ребёнок учится узнавать буквы, цифры и простые слоги.

## Как пользоваться

1. Выберите раздел: алфавит, цифры или слоги.
2. Попросите ребёнка назвать показанный символ.
3. Отметьте, знает ребёнок ответ или нет.
4. Повторяйте короткие тренировки регулярно.

## Возможности

- **Буквы, цифры и слоги.** Несколько разделов для первой практики чтения.
- **Совместное занятие.** Взрослый помогает ребёнку отвечать и отмечает результат.
- **Короткие тренировки.** Формат подходит для регулярной практики без длинной подготовки.
- **Отслеживание прогресса.** Можно видеть, какие элементы уже закреплены.
- **Первая ступень.** Подходит перед переходом к приложению для чтения по слогам.

## Заметка

Это приложение помогает закрепить базу: буквы, цифры и простые слоги. Когда ребёнок уверенно узнаёт отдельные элементы, можно переходить к тренировке чтения по слогам.
